## 🎯 Project Overview

SuperKart Sales Forecasting is an end-to-end machine learning
solution designed to predict product-level sales using product
characteristics and store attributes.

The project integrates an optimized Random Forest model with
a Flask REST API and Streamlit application, with Docker used
for containerization.

## 🏗️ Solution Architecture

<div align="center">
  <img
    src="image_SMD/Sales Forecasting Solution Architecture.png"
    alt="SuperKart Solution Architecture"

  />
</div

The architecture connects four key components:

1. **Streamlit Frontend** – Collects product and store inputs.
2. **Flask REST API** – Processes prediction requests.
3. **Random Forest Model** – Generates estimated sales.
4. **Streamlit Results** – Displays predictions to users.
